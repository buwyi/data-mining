# 论文第 6 章测试证据说明（与 `chapter06.tex` 对照）

本目录说明如何在毕业论文「系统测试与方案校验」中引用本仓库的**可复现**自动化结果。

## 1. 单元测试（支撑 TC-D1 / TC-D3 的数据与展示逻辑）

数据源列表字段解析、时间格式化、CSV 预览矩阵等可在无后端环境下验证，对应论文中「数据源生命周期」中与**前端数据处理**相关的条目。

| 论文用例 | 代码位置 | 说明 |
|---------|----------|------|
| TC-D1（列表检索/展示辅助） | `src/types/datasource.test.ts`、`src/utils/datasourceListTimeFormat.test.ts` | 行标签、时间字段、类型推断、列表相对时间文案分支 |
| TC-D3（平面文件预览） | `src/utils/csvPreviewShared.test.ts` | 样例矩阵 `SAMPLE_PRODUCT_MATRIX`（sku/qty/price/note） |

在项目 `frontend` 目录执行：

```bash
pnpm test
```

将终端中 **Tests N passed** 整段复制到实验记录或附录（或导出 CI 日志）。示例叙述（请替换为真实输出）：

> 在 Node.js 20、执行 `pnpm test`，Vitest 共运行 *N* 个用例，全部通过，覆盖数据源 DTO 辅助函数与 CSV 预览构建逻辑。

## 2. E2E 烟测（TC-A1 / TC-A2）

与论文「自动化烟测」一致，Playwright 校验登录页与未登录重定向：

```bash
pnpm test:e2e
```

对应 `e2e/smoke.spec.ts` 中 `TC-A*` 描述。

## 3. 需联调环境的手动用例（TC-D2、TC-P*、TC-C1）

论文已说明：未配置后端基址时接口不可用，应记为**环境阻塞**而非前端逻辑失败。以下建议在真实部署下填写「通过/失败/阻塞」：

| 编号 | 建议操作 |
|------|----------|
| TC-D2 | 在连接测试页提交 JDBC 参数，观察成功或可读错误 |
| TC-D1 分页/检索 | 数据源页输入关键字、切换页码 |
| TC-P1–P3 | 工程树、画布保存、运行/中止 |
| TC-C1 | 组件页拉取算法/控件列表 |

## 4. 粗粒度性能观察（第 6.4 节）

按论文方法：在浏览器开发者工具中记录首屏网络耗时、大文件预览时主线程占用；论文中写**数量级与趋势**，避免虚构精确毫秒值。
